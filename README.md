# Практические работы по программированию на C# (ГБПОУ «КАИТ № 20»)

Все практические работы выполнены строго по инструкциям и шаблону `Пример отчета.docx`. Для каждой практической работы все задания объединены в **единый файл кода C#** с разметкой каждого задания комментариями (`// ==================== Задание 1 ====================`, `// ==================== Задание 2 ====================` и т.д.).

---
