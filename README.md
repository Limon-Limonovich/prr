# Практические задания (Калькулятор, Вариант 11, Вариант 12)

В корне репозитория находятся **3 готовых архива** и **3 отдельные папки**:

1. **[`Калькулятор.zip`](Калькулятор.zip)** (папка [`Калькулятор/`](Калькулятор/)) — Windows Forms приложение «Калькулятор» по заданию (интерфейс с 3 полями и кнопкой `=`, операции `+`, `-`, `*`, `/` с проверкой деления на 0, факториал `!` для `0, 1, -5, 9, 20`) + каркас отчёта `Отчет_Калькулятор.docx`.
2. **[`Вариант_11.zip`](Вариант_11.zip)** (папка [`Вариант_11/`](Вариант_11/)) — простое консольное приложение (`Program.cs`): **Подсчет среднего арифметического цифр числа** + каркас отчёта `Отчет_Вариант_11.docx`.
3. **[`Вариант_12.zip`](Вариант_12.zip)** (папка [`Вариант_12/`](Вариант_12/)) — простое консольное приложение (`Program.cs`): **Сгенерировать ближайшее простое число (большее введенного)** + каркас отчёта `Отчет_Вариант_12.docx`.
