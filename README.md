# Практические работы по программированию на C# (ГБПОУ «КАИТ № 20»)

Все практические работы выполнены строго по инструкциям и шаблону `Пример отчета.docx`:
- Для каждой практической работы написан **один простой файл с кодом C#** (без сложных конструкций), где каждое задание помечено комментарием (`// Задание 1`, `// Задание 2` и т.д.).
- Все отчёты (`.docx` и `.md`) оформлены строго по каркасу `Пример отчета.docx` (титульный лист, цель, задачи, заголовки заданий с местами `[Место для скриншота]` под ваши скриншоты и ответы на контрольные вопросы).
