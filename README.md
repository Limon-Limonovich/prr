## 1. Папка [`Вариант_11/`](Вариант_11/) — Подсчет среднего арифметического цифр числа
- **Проект Visual Studio (Windows Forms):** [`Вариант_11/Calculator.sln`](Вариант_11/Calculator.sln), [`Вариант_11/Calculator.csproj`](Вариант_11/Calculator.csproj)
- **Код логики калькулятора:** [`Вариант_11/CalculatorForm.cs`](Вариант_11/CalculatorForm.cs)
- **Код интерфейса формы:** [`Вариант_11/CalculatorForm.Designer.cs`](Вариант_11/CalculatorForm.Designer.cs)
- **Каркас отчёта Word (`.docx`) с ответами на итоговые вопросы:** [`Вариант_11/Отчет_Вариант_11.docx`](Вариант_11/Отчет_Вариант_11.docx)
- **Инструкция и ответы (`.md`):** [`Вариант_11/README.md`](Вариант_11/README.md)

### Что вводить в калькуляторе (Вариант 11):
- **Базовые операции (Задание 2):** введите первое число, операцию (`+`, `-`, `*`, `/`) и второе число → нажмите `=` (при делении на `0` выводится `Ошибка! Деление на 0`).
- **Факториал (Задание 3):** введите число в первое поле (`0`, `1`, `-5`, `9`, `20`), в поле операции введите `!`, второе поле оставьте пустым → нажмите `=`.
- **Среднее арифметическое цифр (Задание 4, Вариант 11):** введите целое число в первое поле (например, `246` или `1234`), в поле операции введите `avg` (или `ср`), второе поле оставьте пустым → нажмите `=`.
