| Критерий | float | double | decimal |
| --- | --- | --- | --- |

### Задание 5. Письменные вопросы

**1. Чем значимые типы отличаются от ссылочных?**  
Значимые типы (int, double, bool, char, struct) хранят само значение напрямую, а при копировании создаётся новая независимая копия. Ссылочные типы (string, object, массивы, классы) хранят ссылку на объект в памяти (куче).

**2. Что такое стек и куча? Как это связано с типами C#?**  
Стек — быстрая память для локальных переменных значимых типов, которая очищается автоматически при выходе из метода. Куча (heap) — область памяти для объектов ссылочных типов, которую очищает сборщик мусора (GC).

**3. Почему double нежелательно использовать для денежных расчётов?**  
Потому что double хранит числа в двоичном виде и даёт небольшие ошибки округления в десятичных дробях (например, 0.1 + 0.2 != 0.3). Для денег используют decimal.

**4. Чем var отличается от dynamic? Когда можно использовать var?**  
У var тип определяется компилятором один раз при объявлении и дальше меняться не может. У dynamic тип проверяется только во время работы программы. Использовать var можно для локальных переменных, когда их тип сразу понятен из правой части.

**5. Что такое nullable-тип? Как объявить переменную, которая может хранить null?**  
Это значимый тип, которому разрешено принимать пустое значение null. Объявляется с помощью знака вопроса после типа: например, int? a = null;.

**6. Чем Convert.ToInt32 отличается от int.Parse и int.TryParse?**  
int.Parse переводит только строку и при ошибке вызывает исключение. Convert.ToInt32 умеет переводить разные типы и для null возвращает 0. int.TryParse не вызывает ошибку при неверном вводе, а просто возвращает false.

**7. Что произойдёт при переполнении типа в режимах checked и unchecked?**  
В режиме checked программа выдаст ошибку OverflowException. В режиме unchecked (по умолчанию) ошибка не выдаётся, а число перейдёт по кругу с начала диапазона.

**8. Чем while отличается от do-while? Когда удобнее использовать for?**  
В цикле while условие проверяется до начала шага (может не выполниться ни разу), а в do-while — после шага (выполнится хотя бы один раз). Цикл for удобен, когда заранее известно точное число повторений.

**9. Чем break отличается от continue?**  
Оператор break полностью завершает цикл, а continue пропускает только текущий шаг и переходит к следующему.

**10. Как работает switch? Можно ли использовать switch со строками?**  
Оператор switch сравнивает значение переменной со списком вариантов case и выполняет нужную ветку. Да, в C# switch можно использовать со строками (string).

**11. Почему выражения a + b * c и (a + b) * c дают разные результаты?**  
Потому что умножение (*) имеет более высокий приоритет, чем сложение (+). Скобки () меняют порядок действий и заставляют сначала выполнить сложение.

**12. Что такое неявное преобразование? Приведите 2–3 примера.**  
Это автоматический перевод из меньшего типа в больший без потери данных. Примеры: int a = 5; double b = a; или byte x = 10; int y = x; или int n = 100; long m = n;.

## Контрольные вопросы:

**1. Что такое переменная в программировании?**  
Именованная область памяти для хранения значения определённого типа.

**2. Чем отличается тип данных от переменной?**  
Тип данных определяет вид и размер значений, а переменная — конкретная ячейка памяти этого типа.

**3. Какие существуют основные группы типов данных в C#?**  
Значимые (Value types) и ссылочные (Reference types).

**4. В чем разница между float, double и decimal?**  
В разрядности и точности: float (32 бит), double (64 бит), decimal (128 бит, для финансовых расчётов).

**5. Почему при делении 7 / 2 получается 3?**  
Оба операнда типа int, поэтому выполняется целочисленное деление с отбрасыванием дробной части.

**6. Чем отличается = от ==?**  
= — оператор присваивания, == — оператор сравнения на равенство.

**7. В чем разница между && и ||?**  
&& (логическое И) истинно, когда оба условия истинны; || (логическое ИЛИ) истинно, когда хотя бы одно условие истинно.

**8. Что делает оператор %?**  
Вычисляет остаток от целочисленного деления.

**9. В чем разница между явным и неявным преобразованием типов?**  
Неявное выполняется автоматически без потери данных, а явное требует указания типа в скобках.

**10. Чем отличается int.Parse() от int.TryParse()?**  
int.Parse() при ошибке вызывает исключение, а int.TryParse() возвращает false без аварийного завершения.

**11. Что произойдет, если пользователь введет буквы вместо числа при использовании int.Parse()?**  
Произойдёт ошибка времени выполнения FormatException.

**12. В каком случае нужно использовать тип bool?**  
Для хранения логических значений true или false в условиях и циклах.
