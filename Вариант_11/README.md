# Практическое занятие: Разработка калькулятора (Вариант 11)
**Индивидуальное задание (Вариант 11):** Подсчет среднего арифметического цифр числа

---

## Как запустить и что вводить в поля калькулятора
1. Откройте `Calculator.sln` в Visual Studio и нажмите **F5**.
2. В верхнем ряду расположены три поля: **Первое число**, **Операция**, **Второе число**.
3. Поддерживаемые операции:
   - `+`, `-`, `*`, `/` — введите оба операнда и операцию посередине (при делении на `0` выводится `Ошибка! Деление на 0`).
   - `!` — факториал числа из первого поля (второе поле можно оставить пустым). Проверьте для значений из задания: `0` (→ `1`), `1` (→ `1`), `-5` (→ `Ошибка! Число не может быть отрицательным`), `9` (→ `362880`), `20` (→ `2432902008176640000`).
   - `avg` (или `ср`) — Вариант 11: подсчет среднего арифметического цифр числа из первого поля (второе поле оставляется пустым). Например: число `246` → операция `avg` → результат `4`.

## Подведение итогов (ответы на вопросы)

**1. Какой из этапов разработки калькулятора оказался для вас самым трудным?**  
Самым ответственным этапом оказалась проверка корректности пользовательского ввода и обработка граничных случаев: деление на ноль, вычисление факториала для числа 20 без переполнения типа (использование типа long вместо int) и работа унарных операций при пустом втором поле ввода.

**2. В вашем варианте вам труднее было справиться с алгоритмической или с математической частью?**  
Труднее была алгоритмическая часть: нужно было правильно организовать цикл while для последовательного выделения цифр числа с помощью остатка от деления на 10 (% 10) и целочисленного деления (/ 10), а также учесть отрицательные числа и число 0.

**3. Пользовались ли вы при выполнении заданий искусственным интеллектом? Много ли пришлось адаптировать код от ИИ для своего проекта?**  
При выполнении работы использовались справочные материалы по C# и Windows Forms, а сам алгоритм с циклами и проверками условий был написан и протестирован под требования задания и имена элементов управления формы.
